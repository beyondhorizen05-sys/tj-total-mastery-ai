# Contributing to TJ

Issues and pull requests are welcome. Keep changes focused and explain the user-facing behavior. Before submitting a pull request, run `pnpm install`, `pnpm run typecheck`, `pnpm run lint`, and `pnpm run test`.

Do not include personal data, credentials, local vault files, `.env`, or `.tj-data`. Use disposable test values and temporary test databases. Avoid claiming a live external integration works based only on mocks.

The local web UI and Node API are the current development targets. The Tauri shell is still incomplete as a standalone installer.
